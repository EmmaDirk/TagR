# Leg preference slider for all players

Places each player on a left-to-right slider based on leg usage and
success. BOTH pulls toward the center. Only uses shot types SHORT, LONG,
FREE-BALL.

## Usage

``` r
tagr_plot_leg_preference_slider(df)
```

## Arguments

- df:

  A TeamTV shots data.frame.

## Value

A ggplot object.
